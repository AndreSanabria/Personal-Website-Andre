# Andre Sanabria Personal Website

Personal website for Andre Sanabria, a Computer Science graduate from the University of Texas at Dallas. The site presents selected software projects, technical skills, contact links, and a responsive animated landing page.

## Featured Projects

### EquityLens

C#/.NET stock research dashboard that combines market data, SEC filings, ranked news, watchlists, snapshots, and transparent risk scoring into one company research view.

- Repository: https://github.com/AndreSanabria/EquityLens
- Stack: C#, ASP.NET Core, Entity Framework Core, SQLite, React, TypeScript

### SupportOps Portal

ASP.NET Core MVC operations dashboard for incident tracking, system health monitoring, SQL diagnostics, knowledge articles, and customer update drafting.

- Repository: https://github.com/AndreSanabria/SupportOps-Portal
- Stack: C#, ASP.NET Core MVC, Entity Framework Core, SQLite, SQL Server, Serilog

### XYZ Data Platform

Node.js, Express, and MySQL application for managing normalized business operations data across employees, vendors, products, applications, interviews, sales, and reporting workflows.

- Repository: https://github.com/AndreSanabria/XYZ-cloud-platform
- Stack: Node.js, Express, MySQL, Bootstrap, SQL

## Local Development

```bash
npm run build
```

The optimized site is generated in `dist/` and can be opened locally from `dist/index.html`.
